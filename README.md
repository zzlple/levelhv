# levelhv

iPhone 免签名网页水平仪（车载版）：气泡盘 + 双轴数字读数 + 接近角/离去角限位 + 超限嘀嘀嘀报警。

https://zzlple.github.io/levelhv/

须 HTTPS 打开方可获取设备方向权限（iOS 13+ 需点一次「启用传感器」授权）。

## 车辆通过性限位（荣放 RAV4 2020 款及以后）

- 官方数据：接近角 18.1° / 离去角 20.3°
- 页面采用保守限位：接近角 APPROACH = 17°、离去角 DEPARTURE = 19°（各留约 1° 余量，避免剐蹭左右前杠下沿与后排气管）
- 提前预警带 = 3°（接近 14° / 离去 16° 开始慢速单响）
- 超过限值 → 屏幕红色告警 + 三连急响「嘀嘀嘀」+ 震动（每秒一轮）
- 气泡位置按各自限位角归一化：气泡压到限位虚线即为达到保守极限
- 中央圆球缩小至盘径 15%，球面默认只显示纵向（LONGITUDINAL）数值，横向与合成值看下方卡片

## 用法

1. iPhone Safari 打开链接，点「启用传感器」并允许运动与方向权限
2. 手机背面贴车、屏幕朝上，长边对准车身纵向
3. 「↕ 车头」按钮切换手机顶部朝车头 / 朝车尾，屏幕上下限位线会自动对调
4. 「🔔」开关音效；测通过角时不要点「校准置零」，保持绝对倾角读数
5. Safari 分享 →「添加到主屏幕」，从桌面图标打开即全屏
